# Contacts Management System

A desktop application built using C# and Windows Forms to manage contact information through a simple and user-friendly interface.

## Overview

The Contacts Management System allows users to add, view, and edit contact information, including names, email addresses, phone numbers, dates of birth, countries, addresses, and profile pictures.

The project follows a Three-Tier Architecture to separate the presentation layer, business logic, and data access logic, making the application easier to maintain and extend.

## Features

- Add new contacts.
- View and edit existing contact information.
- Manage names, email addresses, and phone numbers.
- Store dates of birth, countries, and addresses.
- Upload and remove contact profile pictures.
- Organize application logic using a Three-Tier Architecture.

## Project Architecture

The solution consists of three main projects:

- **Presentation Layer:** `ContactsProject-WinForm`
- **Business Logic Layer:** `ContactsBusinessLayer`
- **Data Access Layer:** `ContactsDataAccessLayer`

## Technologies Used

- C#
- Windows Forms
- .NET Framework
- SQL Server
- Visual Studio

## Getting Started

1. Clone or download this repository.
2. Open `ContactsProject-WinForm/ContactsProject-WinForm.sln` in Visual Studio.
3. Configure the database connection in `App.config` according to your local SQL Server setup.
4. Ensure the required database and tables are available.
5. Build and run the application.
